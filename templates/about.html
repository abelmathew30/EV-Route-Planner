About & How It Works

A project demonstrating AI-powered EV route optimization with real search algorithms.

🔍 Problem Statement

Standard GPS navigation solves: "Find the shortest path from A to B."

EV navigation must solve: "Find the optimal path from A to B, given that the vehicle has a limited battery and must stop to recharge."

Normal Navigation
State = location

Find shortest path from A to B.

EV Navigation
State = (location, battery)

Find optimal path respecting battery constraints and charging opportunities.

📐 Methodology

Graph Representation

The road network is a weighted directed graph G = (V, E) where V is the set of cities/junctions and E is the set of roads. Each edge e ∈ E has: distance (km), speed (km/h), traffic factor.

effective_speed = base_speed / traffic_factor
travel_time = distance / effective_speed
energy = distance / efficiency_km_per_kWh
Battery-Aware A* State Space

The state is (node, battery%) discretized in 5% steps to keep the state space finite. Two transition types:

DRIVE: (n, b%) → (n', b' = b - energy/capacity × 100%)
if energy_needed ≤ usable_energy
CHARGE: (n, b%) → (n, b_target%)
if charging station available at n
Multi-Objective Cost Function
cost = α·(t_travel/T_max) + β·(t_charge/C_max) + γ·(cost_INR/P_max) + δ·(energy/E_max)

All metrics are normalised to [0,1] before weighting to prevent unit-scale dominance.
