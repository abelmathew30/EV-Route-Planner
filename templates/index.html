How the AI Search Works

A simplified view of the Battery-Aware A* algorithm

EV State Space

Normal navigation tracks only location. EV navigation must track:

State = (location, battery_percentage)

This means the search explores combinations of where you are AND how much battery you have at every step.

A* Formula
f(n) = g(n) + h(n)
g(n) — Actual Cost Accumulated driving + charging cost from start to node n
h(n) — Heuristic Estimated minimum remaining cost (haversine distance to goal)
